# GENEVIEVE LISTENS™ — Standalone Demonstration V1

This is a **separate program** created for Tracey Kennedy to give to Irene for clinical, ethical and workflow review. It is not part of Irene’s existing practice-safety build and does not alter that build.

## What works in this demonstration

- Compassionate conversation modes: listen, company, celebration and one-problem support.
- Transparent local-only scripted companion demonstration.
- Person-controlled memory with save, edit, export and delete.
- Pet/dependant-aware safety preferences.
- Direct safety-question pathway with saved preferences incorporated into wording.
- Quiet “Stay with me” check-in timer.
- Closed-loop **No Lost Referral** board with owner, promise deadline, accepted handover and missed-callback escalation.
- Irene review checklist, notes and export pack.
- Installable PWA shell and offline cache.

## Important scope

This V1 does not include a live language model, clinician monitoring, service integrations, emergency dispatch, medical advice or production security. It is a discussion and workflow prototype. A live system requires clinical governance, privacy/security engineering, legal review, rigorous self-harm safety evaluation and verified service handover integrations.

## Open locally

1. Extract the ZIP.
2. Open a terminal in this folder.
3. Run `python -m http.server 8080`.
4. Open `http://localhost:8080`.

Directly opening `index.html` also works for most features, but install/offline behaviour needs a local web server.

## Deploy to Vercel

Upload this folder as a new, separate Vercel project. Do not merge it into the Irene practice repository.


## V2 additions

- Quick, time-stamped capture for moments when the person cannot explain everything.
- Explicit marking of dissociation, lost time, uncertainty and incomplete recall.
- Structured event record with circumstances, emotion, body signs, safety, actions, barriers, outcomes and current needs.
- Audience-specific summaries for health professionals, trusted friends, family or support services.
- Person review, redaction and specific consent before an approved version is saved.
- Exact words are separated from possible themes; themes are labelled for confirmation and never presented as diagnoses.
- Approved summaries are not sent automatically. A local audit record shows the intended recipient and consented version.

## Production caution

The static demo uses transparent local rules, not a clinical AI model. Any production AI analysis requires clinical governance, privacy impact assessment, security controls, evaluated self-harm behaviour, human oversight and verified handover acceptance.
