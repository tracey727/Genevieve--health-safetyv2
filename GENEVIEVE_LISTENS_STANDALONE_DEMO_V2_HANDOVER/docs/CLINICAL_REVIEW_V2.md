# V2 review questions for Irene

- Does the structured summary contain the information a clinician needs without becoming a pseudo-assessment?
- Are self-reported safety states labelled clearly enough?
- Is the distinction between direct quote, person report, possible theme and unknown information obvious?
- Are dissociation and memory gaps handled without pressure or invented certainty?
- What minimum information belongs in a 30-second, one-page and detailed handover?
- When should the summary prompt urgent medical assessment?
- How should consent, withdrawal, retention and access be implemented in production?
- Which recipients need different privacy filters?
- How should receipt, acknowledgement and responsibility acceptance be verified?
- What adverse-event and false-summary testing is required before trial?
